# Task2-EDA-Business-Intelligence
📌 Project Objective

The objective of this project is to perform exploratory data analysis and SQL-based business intelligence on the cleaned Superstore dataset.

🛠 Tools Used
Python (Pandas, Matplotlib)
SQLite (SQL queries executed in Google Colab)
GitHub for project documentation

📊 Exploratory Data Analysis

The following analysis was performed:
Dataset overview and structure analysis
Descriptive statistics
Sales distribution visualization
Region-wise revenue analysis
Category-wise revenue analysis
Correlation analysis

🗄 SQL Business Queries

The following business questions were answered using SQL:
Top 5 revenue-generating products
Sales distribution by region
Category-wise revenue analysis
Top 10 customers by revenue
Average shipping time by region

📈 Key Insights

West region generates the highest revenue
Technology category contributes the most sales
A small group of customers drive significant revenue
Shipping time varies across regions indicating operational differences
